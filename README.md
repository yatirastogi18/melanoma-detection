# MedFairXNet: A Fair and Robust Deep Learning Framework for Melanoma Detection

## Overview

This repository contains the implementation of a melanoma detection system developed using dermoscopic image analysis, image preprocessing, lesion segmentation, and deep learning techniques.

The project investigates multiple state-of-the-art deep learning architectures and proposes the MedFairXNet framework for robust melanoma classification.

## Datasets

- HAM10000
- ISIC 2018
- PH2

## Methodology

- Hair Artifact Removal
- CLAHE Enhancement
- Color Normalization
- U-Net Lesion Segmentation
- Deep Learning Classification

## Models Evaluated

- ResNet101
- DenseNet121
- EfficientNetV2-S
- ConvNeXt Tiny
- Swin Transformer
- Proposed MedFairXNet

## Evaluation Metrics

- Accuracy
- Precision
- Sensitivity
- F1-Score
- ROC-AUC
